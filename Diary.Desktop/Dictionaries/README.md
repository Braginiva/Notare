# Словари для проверки орфографии

Hunspell-словари, встроенные в приложение (проверка работает без интернета).

| Файл | Словарь | Источник | Лицензия |
|---|---|---|---|
| `ru_RU.aff`, `ru_RU.dic` | Русский (146 269 слов) | [LibreOffice/dictionaries](https://github.com/LibreOffice/dictionaries/tree/master/ru_RU), автор — Alexander I. Lebedev | BSD-подобная, см. `LICENSE-ru_RU.txt` |
| `en_US.aff`, `en_US.dic` | Английский (США, 49 568 слов) | [LibreOffice/dictionaries](https://github.com/LibreOffice/dictionaries/tree/master/en), автор — Marco A.G.Pinto | GPL, см. `LICENSE-en_US.txt` |

Пользовательские слова («Игнорировать» / «Всегда игнорировать») хранятся отдельно,
в `%AppData%\Notare\user.dic`, и эти файлы не изменяются.
